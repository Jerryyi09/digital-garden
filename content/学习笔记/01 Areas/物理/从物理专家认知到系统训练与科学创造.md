# 中学物理学科包：从物理专家认知到系统训练与科学创造


如果几何学科包的核心是心中成图，AI 工程学科包的核心是心中运行，那么物理学科包最值得深入研究的专业认知内核是：

**心中建模——在头脑中重建物理世界的运行机制，并通过模型、数学、实验与证据不断逼近真实世界。**

但物理的专业认知不能仅仅归结为心理模拟。物理学家还需要从复杂现象中识别关键变量，选择研究对象，建立理想化模型，发现约束和守恒关系，进行定量预测，设计实验，并在理论与现实不一致时修正模型。

因此，建议物理学科包同时建设两条紧密咬合的训练主线：

- **物理建模与问题解决**：从物理现象出发，建立可推演、可计算的模型，解决复杂物理问题。
- **科学探究与模型验证**：从观察、预测、实验、证据和反常现象出发，建立、检验、比较和修订模型。

前者直接服务于中学物理学科思维和压轴题解题能力，后者则服务于科学研究、实验探究和真实世界的创新实践。

二者不是两种相互独立的课程，而是同一个物理认知过程的不同侧面。

## 一、物理专业认知的核心：不只是解题，而是建立可以运行的世界模型

与其他学科相比，物理学拥有非常深厚的学科教育研究基础，即 PER（Physics Education Research，物理教育研究）。

其中，专家—新手差异研究、Modeling Instruction、ISLE、多表征推理、科学意义建构等研究，为开发专业技能训练提供了相当成熟的理论和实践资源。

我建议将这些研究熔铸成以下认知主轴。

![[Pasted image 20261127142454.png]]

这套架构包含四种不可相互替代的物理能力。

| 能力 | 核心问题 |
| ---- | ---- |
| 物理洞察 | 这个现象的本质是什么？ |
| 物理推演 | 如果条件发生变化，系统将如何演化？ |
| 定量建模 | 怎样用数学准确表达机制与约束？ |
| 科学检验 | 有什么证据说明我的模型是可靠的？ |

初学者往往先搜索题目中出现了哪些已知量，判断应该套用什么公式。

这才是值得通过学科包反复训练的专业认知。

# 二、内容研究支柱：深入挖掘物理专家认知的理论根基

## 2.1 Chi、Feltovich 与 Glaser：专家看见的是物理原理，而不是题目外观

1981 · 专家—新手知识表征研究

这项经典研究对于物理学科包的意义，相当于 Koedinger 对几何刻画思维课的意义。

研究发现，专家与新手对物理问题的分类依据存在重要差异：专家更多依据问题背后的物理原理，新手则更多依赖滑轮、斜面、弹簧等表面特征。后续研究进一步发展了这种问题分类方法，用于评价物理专业能力。
![[Pasted image 20261127142548.png]]

### 对学科包的直接启发：建立物理原理块训练

类似于几何专家的构型块，物理学习也需要形成具有明确适用条件和推理功能的认知单元。

建议称之为**物理原理块**（Principle-based Schemas）。

每个原理块应当包括：

| 组成 | 示例：平衡模型 |
| ---- | ---- |
| 触发条件 | 物体加速度为零，或满足相应静力学条件 |
| 研究对象 | 单个物体或选定系统 |
| 核心关系 | 合力为零；刚体平衡还需考虑合力矩 |
| 推理功能 | 求未知力、分析约束与临界状态 |
| 不变量 | 给定条件下的平衡关系 |
| 失效边界 | 物体发生加速运动；遗漏重要相互作用 |
| 可组合模型 | 摩擦、杠杆、浮力、连接体 |

必须注意："物理原理块"是借鉴专家分类研究后提出的课程研发概念，不是 Chi 等人原论文中已经验证的训练卡体系。

最有价值的训练并不是让学生记住模型名称，而是让学生能够判断：

**看似不同的问题，为什么本质相同？看似相同的问题，为什么必须采用不同物理原理？**

这可以形成两个领域专属任务族：

- **异形同理**：不同情境，共享深层物理原理。
- **同形异理**：外观相似，但关键条件改变，必须切换原理。

## 2.2 Heller、Reif、Dufresne：专家的物理问题表征与求解规划

1980—1990年代的物理问题解决研究不仅描述了专家—新手差异，还尝试将专家分析问题的过程显性化，训练学生建立理论性问题描述、按照物理原理进行层级分析。

Heller 与 Reif 1984年的研究，以及 Dufresne 等人关于层级问题分析的研究，都值得作为物理压轴题训练的核心依据。

它们给出的重要启发是：**物理问题解决应当在代数计算之前，建立能够指导计算的物理表征。**

建议提炼出五项专业操作：

| 操作 | 需要训练的能力 |
| ---- | ---- |
| 对象选取 | 确定单体、整体或子系统 |
| 相互作用分析 | 判断系统中有哪些实际作用 |
| 过程分段 | 找出规律、约束或运动状态发生改变的节点 |
| 原理调用 | 判断物理定律的适用条件 |
| 求解规划 | 确定中间量、方程依赖与求解顺序 |

这与几何课中的"识别构型—发现一级结论—组织证明骨架"非常相似。

建议建立物理版的求解骨架压缩训练：

`研究对象 → 关键过程 → 物理原理 → 中间量 → 目标量`

在专项训练中，可以暂时不要求学生完成所有计算，集中测量模型选择和求解规划能力；但在综合解题测评中，仍须要求完整、独立的定量求解。

## 2.3 Hestenes、Wells、Swackhamer：Modeling Instruction 建模教学

1995 · 高中物理建模教学

Modeling Instruction 是物理学科包最值得直接借鉴的成熟教学体系之一。

它不把物理知识组织成彼此独立的公式和知识点，而是通过模型发展与模型运用，让学生建立能够解释和预测一类物理现象的模型。该方法曾在高中物理教学中开展研究和实践。

其重要思想可以转化为两个相互循环的学习过程。
![[Pasted image 20261127142658.png]]
例如，学习匀速直线运动，不应只是记忆 \(s=vt\)。

学生还需要通过观察或实验建立运动模型，知道它对位置、时间和速度作出了哪些假设，能够在运动图、数据表、文字和公式之间转换，并识别哪些新情境不再符合匀速模型。

建议将 Modeling Instruction 作为物理学科包的宏观教学骨架，但不要求每个知识点都由学生从零发现。

## 2.4 Kohl、Finkelstein：多表征不是辅助工具，而是专业推理能力

物理专家经常在不同的表示系统之间切换。

2008年 Kohl 与 Finkelstein 的研究，通过访谈考察了专家和新手处理多表征物理问题的方式，涉及自行构建表征和使用已经提供的表征等不同情境。

关键的教学启发不是"每道题画五张图"，而是培养学生**根据问题需要选择合适的表征，并理解不同表征之间的一致性**。
![[Pasted image 20261127142720.png]]
建议学科包覆盖以下表征能力：

| 表征 | 主要认知功能 |
| ---- | ---- |
| 物理情境图 | 建立真实对象和空间关系 |
| 相互作用图 | 明确对象之间谁与谁发生作用 |
| 受力图 | 分离施力对象、方向和力的类型 |
| 运动图 | 表示位置、速度和运动趋势 |
| 能量图 | 追踪储存、转移和耗散 |
| 状态与过程图 | 区分不同阶段及切换条件 |
| 数据与函数图像 | 观察变量之间的关系 |
| 数学方程 | 进行定量推演与约束表达 |

这里最应该开发的任务族是**跨表征重建与一致性辨伪**。

例如给出物体的速度—时间图像，要求学生推断加速度和可能的合力变化；再提供几张受力图，选择与运动情况相容的图，并说明哪些信息仍然无法确定。

这比简单画受力图具有更高的专业认知训练价值。

## 2.5 John Clement：物理专家的心理模拟、思想实验与创造性建模

Creative Model Construction in Scientists and Students · 2008

这是本次研究中我认为最值得深入开采的理论之一。

Clement 的研究直接关注科学家和学生如何利用心理表象、类比、心理模拟和思想实验建立新的科学模型。

其2008年的专著《Creative Model Construction in Scientists and Students》系统讨论了这些认知机制，并通过学生访谈探讨了它们在科学教育中的潜力。

这项研究为物理学科包提供了与几何心象训练极为相似的认知基础。

但物理心理模拟比几何心理动画多了一个重要维度：**不仅模拟对象怎样运动，还要推演为什么这样运动，以及什么机制会改变运动。**

例如，想象一个正在下落的物体：

![[Pasted image 20261127142751.png]]

学生需要在头脑中追踪：

**速度增大 → 空气阻力增大 → 合力减小 → 加速度减小 → 速度增加得越来越慢 → 逐渐接近终极速度。**

这是一条完整的动态因果链。

它不是背诵终极速度定义，也不是观看一个落体动画，而是在头脑中运行一个物理模型。

### 对学科包的直接转化

建议研发五种心理操作：

| 心理操作 | 物理训练 |
| ---- | ---- |
| 动态心理模拟 | 预测物体在不同时间的运动、受力和能量状态 |
| 机制心理模拟 | 想象某个物理机制如何产生可观察结果 |
| 反事实心理操作 | 删除摩擦、改变质量、撤去支撑后重新推演 |
| 思想实验 | 构造极端或理想情境，检验某个物理解释 |
| 创造性建模 | 在原有模型基础上加入新的相互作用、变量或约束 |

这一理论值得与 Hestenes 的建模教学结合起来：

Hestenes 主要提供模型组织教学的骨架，Clement 提供学生怎样在认知层面创造和改变模型的重要研究基础。

## 2.6 diSessa：物理直觉不是简单的错误知识，而是需要重组的认知资源

Knowledge in Pieces · Phenomenological Primitives（p-prims）

传统物理教学经常把学生的错误理解视为需要直接消除的迷思。

diSessa 的理论则强调，学习者的直觉知识可能由许多在不同情境中被激活的微小认知资源组成，例如：

- 作用越强，效果越大；
- 变化需要某种原因；
- 相反作用可能彼此抵消；
- 持续的作用可能产生持续的变化。

这些直觉在某些情境下是合理的，在另一些情境下则可能被错误使用。物理学习的重要任务是重新组织这些资源，使它们能够在适当条件下被正确调用。

例如，学生认为：

"物体运动得越快，受到的力就越大。"

错误不一定来自完全没有理解力，而可能来自把"作用越大，效果越强"的直觉错误地对应到了速度，而非加速度。

因此，物理学科包不能只建立一个"迷思清单"，然后逐条告知学生正确答案。

更好的做法是建立：

**直觉资源 → 激活情境 → 错误映射 → 合理适用条件 → 重组后的科学理解。**

## 2.7 Clement 的 Bridging Analogies：用桥接类比重构直觉

1993年 Clement 关于桥接类比与锚定直觉的研究，是上述思想非常成熟的教学实践。

它首先寻找学生本来就具有的正确直觉，再通过一系列中间情境，将这些直觉连接到学生难以接受的物理模型。相关研究被美国国家研究委员会的 K–8 科学教育综述讨论。

以理解桌面对物体的支持力为例：
![[Pasted image 20261127142819.png]]

学生通过连续改变支撑物的刚度，建立一个更加连贯的解释：**看不见明显形变，并不意味着不存在接触作用。**

这一机制可以沉淀为**锚定直觉—桥接情境—机制重组—陌生情境检验**的训练范式。

它比直接制造认知冲突然后宣布正确答案更细致，也更能保护学生主动探索的信心。

## 2.8 Tuminaro 与 Redish：物理专家会切换不同的认知推理游戏

Epistemic Games · 2007

这项研究非常值得 Course Creator 关注。

Tuminaro 与 Redish 用 Epistemic Games（认识论游戏）描述学生在解决物理问题时，如何进入具有特定目标、知识资源和操作规则的推理模式。

例如：

| 推理模式 | 学生主要在做什么 |
| ---- | ---- |
| 物理机制推理 | 根据相互作用解释现象 |
| 表征推理 | 利用图像或图示建立关系 |
| 意义映射到数学 | 从物理情境建立方程 |
| 数学映射到意义 | 从数学关系反推物理含义 |
| 公式递进计算 | 根据已知量和未知量组织计算 |

该研究不是要求学生避免数学计算，而是提示教师：**学生可能进入了不适合当前问题的推理模式。**

例如学生一直在尝试代公式，却没有建立系统边界；或者学生能够进行定性解释，却不会将解释转化为定量关系。

2018年关于 Sensemaking Epistemic Game 的研究，以及2023年关于意义建构与科学建模相互关系的研究，进一步提供了分析物理理解过程的视角。

对学科包的直接意义是：**不仅训练方法本身，还要训练何时使用方法、何时停止、何时切换方法。**

## 2.9 Kuo、Hull、Gupta 与 Elby：数学推理必须始终带着物理意义

这是解决物理压轴题训练中"数学会做，却看不懂物理"的重要研究方向。

Kuo 等人的研究指出，物理问题解决中的专业能力还包括在操作方程的过程中，将直觉概念推理与形式化数学推理有机结合，而不只是先分析物理、再机械计算、最后检查答案。

例如，在恒定合力条件下：$a=\frac{F}{m}$

不能只会代数变形，还应该理解：

- 固定质量时，合力增大意味着加速度增大；
- 固定合力时，质量增大意味着运动状态更难改变；
- 合力为零时，加速度为零，但速度不一定为零；
- 若合力方向改变，加速度方向也发生改变。

这些理解可以直接参与计算、策略选择和错误检验。

2026年发表于 Physical Review Physics Education Research 的一项研究进一步考察了显式教授物理方程意义建构策略的教学干预。另一项同年10月发表的概念验证研究，则考察了极限情境分析训练的剂量—效果关系。两者都为这一方向提供了新的研究依据，但研究对象主要是本科生，不能直接外推到初中。

建议物理学科包将以下方法作为**独立训练对象**：

- 量纲检查；
- 数量级估算；
- 单调性与比例关系；
- 极限情境分析；
- 特殊值检验；
- 数学表达的物理意义解释；
- 从定性约束预判计算结果的范围。

这些都应当是物理专业认知的一部分，而不是计算结束后的形式性检查。

# 三、教学法研究支柱：最值得系统吸收的物理教学实践

前面研究的是物理专家如何思考，接下来要回答：怎样让中学生逐步获得这些能力？

我建议不选择某一种教学法作为万能方法，而是根据不同认知目标组合成熟的教学实践。

## 3.1 ISLE：让学生以物理学家的方式建立知识

Investigative Science Learning Environment · Etkina & Van Heuvelen

ISLE 是整个物理学科包最值得采用的科学探究教学体系之一。

其核心不是让学生按照既定步骤验证老师已经告诉他们的规律，而是让学生经历类似物理学家建立和应用知识的过程。

ISLE 特别重视实验设计、模型建构、多表征、假设评价、测量不确定性和科学交流等能力，并配有 Scientific Abilities Assessment Rubrics（科学能力评价量规）。相关研究还考察了学生在自主设计实验时的科学家式行为。
![[Pasted image 20261127143242.png]]
我特别建议在学科包中明确三类实验的区别。

| 实验类型 | 目的 | 学生主要认知动作 |
| ---- | ---- | ---- |
| 观察性实验 | 发现现象和规律 | 识别变量、发现模式 |
| 检验性实验 | 检验不同解释 | 预测、设计鉴别条件、评价证据 |
| 应用性实验 | 利用已建立的模型解决问题 | 建模、测量、计算、验证 |

传统中学物理实验教学很容易出现一个问题：**学生能够按照教材操作，得到预期结果，却不知道为什么这样设计实验。**

ISLE 能够帮助 Creator 将实验从"操作任务"转化为"科学推理任务"。

尤其重要的是：**一个实验如果无法区分竞争性解释，就不应声称它验证了其中某一种解释。**

建议将这条规则写入物理学科包的实验设计审查部分。

## 3.2 TIPERs：物理思维专项训练的成熟题目范式

Tasks Inspired by Physics Education Research

如果要寻找类似几何学科包"八种训练范式"的成熟实践，TIPERs 是非常值得参考的资源。

它包含一系列面向物理概念理解和推理困难的短任务，包括排序题、冲突观点题、故障诊断题等。

PhysPort 特别指出，这些任务的结构和内容具有物理教育研究基础，但不能据此宣称整个最终题集已经得到直接的学习效果验证。

| 成熟任务范式 | 训练价值 |
| ---- | ---- |
| Ranking Tasks 排序任务 | 比较变量关系、控制条件和相对量级 |
| Conflicting Contentions 冲突观点 | 评价不同物理解释 |
| Troubleshooting 故障诊断 | 发现物理表征或推理中的错误 |
| 表征转换 | 在文字、图像、图示和方程之间转换 |
| 比较辨析 | 识别真正决定结果的关键条件 |

### 示例：力与运动排序任务

## 3.3 FCI 与概念诊断：识别公式正确背后的物理理解错误

Hestenes 等人在1992年开发的 Force Concept Inventory（FCI，力概念量表），以及后来的 FMCE、TUG-K 等研究型测评工具，构成了力学概念诊断的重要资源。

对于物理学科包，最值得借鉴的不是直接复制 FCI 题目，而是学习它的命题思想：

**干扰选项应当代表有认知意义的错误模型，而不是随意编造的错误答案。**

例如，针对力与运动的理解，建议分别检测：

| 认知混淆 | 鉴别方向 |
| ---- | ---- |
| 速度与加速度混淆 | 快速运动是否必然具有较大加速度 |
| 力与速度混淆 | 匀速运动是否需要非零合力 |
| 作用力与平衡力混淆 | 两力作用在同一物体还是不同物体 |
| 静摩擦力与最大静摩擦力混淆 | 摩擦是否必须达到某个固定值 |
| 惯性与力混淆 | 停止施力后，物体是否仍然运动 |

注意，这些只能作为**候选迷思及鉴别方向**。不能因为学生一次选错就认定其具有稳定的错误认知模型。

另外，FCI 等正式量表有特定适用学段和使用条件，不宜直接照搬至所有初中课程，也不应将其正式测评题公开作为训练题使用。应优先依据其构念和命题思想研发独立变式。

## 3.4 Peer Instruction：让竞争性解释成为课堂认知活动

Mazur 的 Peer Instruction（同伴教学）在大学物理教学中积累了较长时间的实践与研究，关注概念推理和定量问题解决。

对于一对一 AI 教学，可以借鉴它的认知活动结构：

`独立判断 → 比较不同观点 → 提出物理依据 → 再次判断 → 新情境验证`

AI 可以模拟两种有真实认知意义的竞争性解释，让学生判断，而不是直接宣布答案。

例如：

> 甲认为正在向上运动的小球受到向上的合力；乙认为忽略空气阻力时，小球离手后只受到重力。

学生需要说明速度方向和合力方向为什么不一定相同，并通过运动图或变化趋势检验自己的判断。

不过，AI 模拟竞争观点并不等价于真实同伴讨论，原有 Peer Instruction 的教学效果证据不能自动迁移到这种一对一环境。

## 3.5 PhET 与仿真实验：预测必须先于操作

PhET 的研究不仅关注模拟工具是否生动，还研究什么样的交互特征能够支持学生提出问题、探索关系和建立理解。

建议继承几何包与 AI 包已有的预测优先原则，在物理实验和仿真中采用：

`心中预测 → 真实实验或仿真 → 差异比较 → 机制解释 → 变式再预测。`

关键在于实验或仿真应该用于检验学生自己的物理模型，而不是替学生生成物理直觉。

同时必须区分：

- 数学模型的可视化；
- 基于规则的计算机仿真；
- 真实物理世界的测量数据。

仿真结果能够检查学生对仿真规则的理解，但同一模型生成的仿真结果不能独立证明该模型符合现实世界。

这应成为物理学科包特有的科学认识论红线。

Zwickl 等人在2015年提出的物理实验建模框架，特别强调实验中不仅存在对物理系统的建模，还存在对测量工具和测量过程的建模。

例如，学生测量物体下落时间时，秒表不是直接提供真实时间的魔法工具。

测量结果可能包含反应时间、仪器分辨率、起止条件定义和操作误差。

# 四、研究熔铸的最终成果：物理专家认知的九大技能域

综合前述内容研究与教学法研究，我建议不要简单按力、热、声、光、电划分学科包的能力体系。

知识模块回答的是学生正在研究什么；专业技能域回答的是学生正在执行什么物理认知操作。

建议建立九大技能域。

| 技能域 | 专业认知内核 | 典型学生交付 |
| ---- | ---- | ---- |
| P1 物理刻画 | 识别对象、现象、状态、系统边界及关键变量 | 物理情境模型 |
| P2 原理识别 | 穿透表面情境，识别深层物理规律 | 原理分类及适用依据 |
| P3 相互作用分析 | 识别作用对象、方向、传递和因果关系 | 相互作用图、受力图 |
| P4 心理动态建模 | 在头脑中模拟状态、变化过程及临界条件 | 状态序列、趋势预测 |
| P5 系统与守恒推理 | 追踪系统内部变化、跨边界传递及不变量 | 能量账本、守恒关系 |
| P6 多表征与数学建模 | 在物理情境、图示、图像和方程之间双向转换 | 一致的多表征模型 |
| P7 策略规划与综合求解 | 选择原理、组合模型、逆推中间量和求解路线 | 求解骨架、独立解答 |
| P8 实验与证据推理 | 设计实验、评价测量、区分竞争性解释 | 实验方案、数据与论证 |
| P9 模型修订与科学创造 | 检验边界、修订假设、重构系统、设计新方案 | 修订模型、创新设计 |

这里的 P1–P9 是建议的学科包内部研究分类，不是 Growth OS 中央方法 ID，也不是需要依次通关的九个等级。

这九项技能需要进一步形成前驱、组合和依赖关系。

例如：

- 受力分析通常依赖准确的对象与系统边界选择。
- 运动趋势预测需要协调速度、加速度与合力。
- 能量推理需要明确系统边界与能量传递。
- 综合求解需要整合表征、原理、约束与数学关系。
- 科学实验需要将待检验模型转化为可观察预测。

因此，Creator 应当按学习者缺口选择技能组合，而不是每门课程都覆盖九项。

## 五、物理学科包的核心特色：心中建模的六类心理模型

在此前几何与 AI 学科包的研究中，我们分别提炼出了几何心象与 AI 心理运行。物理学科包可以在两者之间形成一个更具自然科学特色的心理模型体系。

| 模型 | 在头脑中刻画什么 | 核心问题 |
| ---- | ---- | ---- |
| M1 对象—结构模型 | 物体、部件、位置、系统边界 | 世界由哪些相关对象组成？ |
| M2 相互作用模型 | 力、场、热传递、电路中的相互作用 | 对象怎样彼此影响？ |
| M3 状态—过程模型 | 位置、速度、温度、电流等状态随条件变化 | 接下来会发生什么？ |
| M4 因果—机制模型 | 微观机制、宏观效应、反馈与约束 | 为什么会发生？ |
| M5 定量—守恒模型 | 比例关系、数学规律、能量与其他守恒量 | 变化多少？哪些量保持不变？ |
| M6 实验—认识模型 | 假设、测量、预测偏差及模型适用范围 | 我如何知道自己的理解是可靠的？ |

这六类模型是借鉴上述 PER 和认知科学研究形成的综合课程研发候选，不能直接视为已有研究验证过的统一物理认知模型。

### 5.1 从看见物体，走向看见物理过程

以物体逐渐浸入水中的过程为例。

![[Pasted image 20261127143529.png]]

初级学生看见的是一个物体进入水中。

具有物理建模能力的学生应该能够在头脑中同步追踪：

1. 排开液体的体积怎样变化；
2. 浮力怎样变化；
3. 物体重力是否变化；
4. 悬挂装置示数怎样变化；
5. 液体和容器受到的作用怎样变化；
6. 在什么位置原有变化规律发生切换。

当物体完全浸没后，排开液体体积不再增加，浮力在给定模型条件下保持不变。

这就是物理学科中非常重要的**临界点与分段机制识别**。

它与几何动态构型中的切换点相似，但物理还需要追踪力、能量、状态量及模型假设。

### 5.2 从预测趋势，走向解释因果机制

建议要求复杂物理预测形成四层证据。

| 证据层 | 以浸没过程为例 |
| ---- | ---- |
| 状态预测 | 浮力先增大，后保持不变 |
| 机制解释 | 浮力取决于液体密度和排液体积 |
| 条件判断 | 完全浸没且液体密度不变后，排液体积不变 |
| 边界分析 | 物体接触容器底部、发生形变等情况需重新建模 |

仅仅答对"先变大后不变"，不能自动证明学生理解了浮力机制。

# 六、研发物理学科专属的十五类训练范式

建议参考几何包的八种训练范式，但不要套用固定五段心象模板。物理需要同时训练原理辨别、物理心理动画、数学意义建构、科学实验与模型创造。

以下十五类是建议的初始任务族候选。

## A 类：物理洞察与模型识别

| 训练范式 | 学生核心动作 | 可观察证据 |
| ---- | ---- | ---- |
| A1 异形同理 | 对不同表面情境进行深层原理分类 | 原理及共同条件 |
| A2 同形异理 | 找出外观相同但物理机制不同的情境 | 改变的关键条件 |
| A3 系统边界重划 | 在单体、整体、子系统之间重新选取对象 | 边界及内外作用 |
| A4 模型降维与辨伪 | 判断哪些因素可以忽略、哪些不能 | 理想化依据、失效反例 |

其中，A1 和 A2 可以发展为物理版的"构型快认"。

但不应规定每组固定五题，也不应首先追求识别速度。需要先形成准确的原理识别和条件解释。

## B 类：心理动态模拟与物理推演

| 训练范式 | 学生核心动作 | 可观察证据 |
| ---- | ---- | ---- |
| B1 物理消失帧 | 根据初态、终态或机制重建中间状态 | 状态顺序及因果关系 |
| B2 动态量追踪 | 同时追踪多个物理量随过程变化 | 趋势表、函数图像 |
| B3 临界点与分段预测 | 找出约束或规律切换的位置 | 临界条件与前后规律 |
| B4 反事实与思想实验 | 改变一个条件，重新预演系统 | 反事实预测及理由 |

B 类是"心中建模"最具辨识度的专项训练。

特别需要训练学生不是只预测最终结果，而是能够追踪中间状态、变化速度、临界位置与因果机制。

## C 类：多表征与数学意义建构

| 训练范式 | 学生核心动作 | 可观察证据 |
| ---- | ---- | ---- |
| C1 跨表征重建 | 从图像重建运动、受力、能量或数学关系 | 表征一致性 |
| C2 排序与数量关系辨析 | 在多个情境中比较物理量 | 排序、相等或无法判断及依据 |
| C3 方程意义与极限检查 | 解释公式每一项、比例关系和极限行为 | 物理约束、单位、趋势 |
| C4 求解骨架压缩 | 从目标逆推原理、中间量及求解顺序 | 简洁而完整的求解路线 |

## D 类：科学实验与创造性建模

| 训练范式 | 学生核心动作 | 可观察证据 |
| ---- | ---- | ---- |
| D1 竞争假设检验 | 提出不同解释，设计能够区分它们的实验 | 假设、不同预测与鉴别方案 |
| D2 实验异常诊断 | 区分测量误差、操作问题和模型缺陷 | 原因假设及补充证据 |
| D3 模型创造与工程设计 | 构建新模型或装置，预测并验证改进 | 设计方案、测试、修订 |

这些任务族不是相互排斥的。

例如，设计一种更好的保温容器，可以同时涉及系统边界重划、热传递模型、控制变量实验、数据图像解释和工程设计优化。

## 7.3 临界点与分段模型切换

## 7.4 竞争性解释与鉴别实验

假设学生研究某种保温材料，发现使用材料 A 的杯子冷却得更慢。

可能存在多种解释：

- 材料 A 的导热能力较弱；
- 杯子 A 的盖子密封得更好；
- 杯子 A 的初始水温不同；
- 两个杯子的表面积或水量不同；
- 测温方式存在系统偏差。

学生的任务不是立即选一个原因，而是**提出竞争性假设并设计鉴别实验**。

| 规格要素 | 设计要求 |
| ---- | ---- |
| 初始现象 | 可以有多个合理解释 |
| 学生操作 | 提出假设，导出不同的可观察预测 |
| 实验设计 | 控制相关变量或明确无法控制的因素 |
| 测量证据 | 原始数据、测量方法及实验条件 |
| 判定方式 | 观察结果是否能区分候选解释 |
| 失败处理 | 允许结果不确定，设计补充实验 |
| 独立迁移 | 更换材料、装置或研究问题后重新设计 |

这一任务族是将 ISLE 从概念引入转化为真正可执行的科学探究训练的关键。

# 8.1 不同领域的专业认知特色

## 8.2 特别重视能量作为跨物理领域的认知主线

Nordine、Krajcik 和 Fortus 在2011年的中学能量教学研究中，开发了侧重日常非理想化系统中能量变化的课程，而不是只围绕理想系统中的简单定量计算。其目标包括支持综合理解和未来学习。

这对物理学科包有很大的启发。

能量不仅是力学中的一个章节，还可以连接：

- 机械运动；
- 摩擦与内能；
- 热传递；
- 电路与电功；
- 光与辐射；
- 工程效率与能源问题。

建议建立贯穿多个物理课程的能量追踪任务族。

例如，电动汽车制动时：

![[Pasted image 20261127143707.png]]

学生不仅要问能量变成了什么，还要问：

**我选定的系统是什么？能量是在系统内部重新分配，还是跨越系统边界发生转移？哪些过程不能忽略？怎样通过实验或数据验证？**

这样的任务能够使学生形成跨知识章节的物理世界观。

它也符合 NGSS 中学物理科学课程所强调的系统模型、因果关系、能量和物质、稳定性与变化等跨领域概念。

# 九、为中考压轴题建立专属的物理认知训练体系

结合你此前对初中物理力学思维、压轴题能力与提高课程的关注，我建议在物理学科包中单独设立复杂问题解决场景路由，而不是让所有课程都以实验探究为主要形式。

高水平的物理压轴题，本质上往往需要同时处理多个物理模型、多个对象、多个阶段和多个约束。

## 9.1 压轴题的六项关键专业操作

| 操作 | 主要训练目标 |
| ---- | ---- |
| 对象切换 | 在整体法、隔离法和不同系统之间选择 |
| 过程切片 | 发现不同阶段的物理规律及切换条件 |
| 关系提取 | 从题目中提取显性与隐含约束 |
| 一级结论推导 | 由基础规律快速得到局部重要关系 |
| 模型组合 | 将受力、运动、能量、几何等模型连接 |
| 目标逆推 | 从未知量反推需要建立的中间关系 |

这些操作与几何压轴题训练中的构型识别、补图、新构型发现和证明规划有很大的相似性。

不同的是，物理题中的局部结构通常是一个在特定条件下成立的物理模型，而不是单纯的几何图形。

## 9.2 建议开发物理版的"构型演化链"

例如一个物体从斜面滑下，进入粗糙水平面，最后停止。

![[Pasted image 20261127143728.png]]

对于初中阶段，可以侧重能量转化、受力、速度变化和定性推理；对于进阶课程，再引入功—能关系等定量求解。

其训练价值在于让学生不断执行：

**识别局部模型 → 推导一级结论 → 更新系统状态 → 识别下一模型 → 连接完整求解路线。**

这可以成为物理压轴题专项训练的核心范式之一。

## 9.3 建立"物理模型网络"而非单纯题型目录

建议 Creator 在生成力学训练课程时，围绕模型之间的连接关系组织任务。
![[Pasted image 20261127143815.png]]

> 这只是一个力学模型依赖示例，并不代表所有力学问题必须按图中顺序求解。

学生不仅需要熟悉各个模型，还需要知道它们的前驱条件、组合方式、连接量和失效边界。

# 十、从专家认知到可测目标：建立物理学科专属评价体系

这是学科包能否真正落地的关键。

物理教育研究已经具有比较成熟的过程性评价工具，值得直接参考。

## 10.1 Docktor 等人的 MAPS：物理问题解决过程量规

Docktor 等人在2016年发表的物理书面解题评价研究，建立了五个评价维度：

| 原研究评价维度 | 对应能力 |
| ---- | ---- |
| Useful Description | 有效表征题目信息 |
| Physics Approach | 选择适当物理原理 |
| Specific Application of Physics | 将物理原理正确应用于具体情境 |
| Mathematical Procedures | 正确进行数学操作 |
| Logical Progression | 形成清晰且连贯的求解过程 |

这套量规提供了超越最终答案正确率的评价方式。其原始验证主要面向大学入门物理课程。

建议在中学物理学科包中借鉴它的结构，并补充动态心理模拟、模型假设和实验验证维度。

## 10.2 物理认知能力的八维候选评价模型

| 评价维度 | 观察证据 | 不能冒充掌握 |
| ---- | ---- | ---- |
| 对象与边界刻画 | 准确选取研究对象、边界和变量 | 机械抄写已知条件 |
| 原理识别 | 选择正确原理并说明适用条件 | 根据关键词猜公式 |
| 相互作用与机制 | 正确描述作用对象与因果关系 | 只记忆结论 |
| 动态过程推演 | 正确预测中间状态、趋势及切换点 | 猜对最终状态 |
| 多表征协调 | 图、文字、方程相互一致 | 分别画图却相互矛盾 |
| 数学意义建构 | 量纲、关系、趋势和计算均合理 | 只得到正确数值 |
| 求解策略整合 | 完整连接模型及中间量 | 只说出一个正确公式 |
| 科学检验与修订 | 设计实验、评价证据、修订假设 | 按实验步骤得到预期结论 |

这些维度不应简单合成一个总分后就丢弃各项信息，因为诊断不同学生的物理认知瓶颈才是最重要的目的。

## 10.3 可测目标示例：临界点与分段推演

**候选技能 PHYS-S04 · 研究层临时编号**

### 多阶段物理过程与临界状态识别

**测评条件**

提供未见过的物理情境，至少包含一个机制或约束切换点；不预先给出阶段数量、物理模型名称或临界条件。

**学生交付**

独立标出阶段、临界条件、每阶段的主要物理关系，并给出连续过程的趋势预测。

**候选评分量规**

| 评分维度 | 建议满分 |
| ---- | ---- |
| 阶段识别准确性 | 2 |
| 临界条件解释 | 2 |
| 各阶段模型选择 | 2 |
| 状态连接与因果一致性 | 2 |
| 边界条件与结果检验 | 2 |
| **合计** | **10** |

**迁移检验**：改变系统边界、初始状态或相互作用条件，重新进行预测。

> 评分结构为课程设计候选，尚未经过实际题目难度与评分者一致性校准，不能直接作为 Growth OS 正式掌握阈值。

特别建议将"核心物理错误"设为独立记录。例如，如果学生将速度为零等同于合力为零，那么即使其他评分维度较高，也应继续针对该认知混淆进行诊断。

# 十一、建立鉴别性诊断与适应性训练机制

现有三个学科包的共同短板，是能够提供训练方法，但尚未充分建立"错误表现—认知瓶颈—鉴别任务—训练决策"的闭环。

物理学科包特别适合补齐这部分。

> **物理认知瓶颈诊断示例**
>
> **读题后不知道从哪里开始**
>
> 候选原因可能缺少物理表征能力、原理识别能力或求解规划能力。
>
> **鉴别性诊断任务**：先提供完整受力图或过程图，检查能否选择正确原理；再撤除图示，比较表现。
>
> **候选训练方向**：物理刻画、原理分类、求解骨架训练

一次错误不足以确定认知原因。应依据多项可区分任务及支持条件作出判断。

建议将这些诊断规则与 Growth OS 的学情回流机制连接。

Creator 在造课前根据已有学情确定候选认知瓶颈；Runtime 在实际教学过程中，根据学生的预测、图示、公式、解释、实验和独立表现收集证据。

但 Creator 不能事先把这些预测性归因写成已经发生的学生事实。

# 十二、物理学科包特有的教学设计与防错门禁

借鉴几何包的遮图试答、反特例构造，以及 AI 包的防伪证、双重调试等机制，我建议物理学科包建立以下领域审查规则。

| 编号 | 领域门禁 | 主要防止的问题 |
| ---- | ---- | ---- |
| PHY-G1 | 目标认知操作必须真实发生 | 不理解机制，只凭关键词套公式 |
| PHY-G2 | 研究对象及系统边界明确 | 混用不同物体受到的力 |
| PHY-G3 | 物理定义、假设及适用条件明确 | 将特殊关系当成普遍定律 |
| PHY-G4 | 图示、数据、公式、答案物理一致 | 图形和计算互相矛盾 |
| PHY-G5 | 动态过程及临界状态合法 | 跨越切换点仍使用原模型 |
| PHY-G6 | 概念关系与数量关系均经核验 | 正确计算建立在错误模型之上 |
| PHY-G7 | 先收预测，再揭示待检验现象 | 实验演示提前给出答案 |
| PHY-G8 | 实验须与待检验主张相匹配 | 无鉴别能力的实验被当成证明 |
| PHY-G9 | 真实测量、仿真与假想数据严格区分 | 编造实验数据或虚构执行 |
| PHY-G10 | 独立能力与有支持表现分开 | 教师完成建模后学生计算就算掌握 |
| PHY-G11 | 学段、数学工具与实验安全适配 | 无必要超纲、危险实验或不可执行任务 |
| PHY-G12 | 多合理模型与不确定答案合法 | 强迫学生在证据不足时给唯一解释 |

其中需要强调几项物理命题中的高频错误。

## 12.1 受力图必须经过对象一致性检查

![[Pasted image 20261127143840.png]]

每个力都应该能够回答：**谁施加？作用在谁身上？方向是什么？属于哪种相互作用？**

建议把这四个问题作为受力图命题与审计的核心检查，而不是只检查箭头是否画对。

## 12.2 理想化不能隐身

例如，题目需要忽略空气阻力、绳重、滑轮摩擦、热量散失或电源内阻，应当通过题设、模型说明或明确的课程约定给出依据。

不能一边使用真实复杂情境，一边未经说明地套用理想模型。

## 12.3 预测与实验必须防泄题

在需要学生独立预测的实验中，学生阅读可以解释原理与操作方式，但不能提前给出该实验所要检验的具体结果。

不过，如果本轮目标是建立初始概念或学习已有理论，则允许适当讲解和示范。不能把预测优先原则误写成所有物理知识都必须由学生自行发现。

## 12.4 不允许为了制造认知冲突而操纵实验

实验结果如果没有出现预期现象，应当如实记录，检查装置、参数、测量方式、原模型与环境条件。

不能为了完成教学流程伪造"成功的认知冲突"，也不能要求学生修改真实数据以符合教材结论。

# 十三、场景路由：不同类型的物理课应该怎样使用学科包

参考 `writing-craft.md` 和 `ai-practice.md` 的任务路由原则，建议设置五类场景。

| 场景 | 主训练链 | 不应机械要求 |
| ---- | ---- | ---- |
| A. 初中概念理解课 | 直觉诊断、桥接类比、模型建构 | 每轮复杂计算 |
| B. 学科思维与刻画训练课 | 原理快认、心中建模、多表征 | 每轮完成真实实验 |
| C. 压轴题强化课 | 多模型组合、过程切片、策略规划 | 每题从零探索规律 |
| D. 科学实验与研究课 | ISLE、竞争假设、证据、模型修订 | 每次实验得到唯一正确结论 |
| E. 工程创新与物理 PBL | 真实问题、系统建模、设计验证 | 只追求作品完成而忽视物理理解 |

同一个学科包可以支持五类课程，但应由 Creator 根据核心任务决定主训练链。

例如，一门初中光学课若主要训练成像理解，可以使用心中光路推演、多表征和概念辨伪。

一门设计太阳能保温装置的 PBL 课程，则需要结合热学模型、能量账本、实验设计和工程优化。

不应为了复用几何包的已有记录结构而套用 `imagery-5seg` 或 `section_items`。同样，也不应假定现有 Runtime 已经具备持续采集真实实验数据、控制外部实验设备和动态仿真的能力。

# 十四、对中学拔尖学生的进阶设计

结合此前的力学提高课程设计，物理学科包应支持超出常规教材的认知挑战，但不要把"高阶"简单等同于提前学习大学数学。

我建议设置四种课程研发深度。

| 进阶深度 | 特征 | 示例 |
| ---- | ---- | ---- |
| D1 物理直觉 | 理解机制和变化趋势 | 解释物体为何加速、减速 |
| D2 定量模型 | 运用本学段数学建立关系 | 比例、图像、简单方程 |
| D3 复杂系统 | 组合多个模型与阶段，识别反馈和临界 | 连接体、分段摩擦、终极速度 |
| D4 科学创造 | 面对新现象建立模型、设计实验和工程方案 | 数值仿真、实验研究、优化设计 |

这里的 D1–D4 是课程深度建议，不是正式 D-ID 或 Growth OS 的 L1–L4 掌握等级。

针对初中高水平学生，可以通过以下方式拓展物理深度：

| 进阶主题 | 需要获得的认知价值 |
| ---- | ---- |
| 非惯性参考系与等效重力 | 认识观察参考系对物理描述的影响 |
| 空气阻力与终极速度 | 理解反馈、动态平衡和非线性变化 |
| 质心、动量与冲量 | 建立系统整体运动的视角 |
| 圆周运动与向心加速度 | 理解速度大小、方向和运动曲率 |
| 简谐运动 | 理解恢复作用、振动与能量交换 |
| 标度律与数量级估算 | 认识尺寸变化如何影响物理规律 |
| 数值模拟 | 通过离散更新理解连续物理过程 |
| 测量不确定性 | 理解科学结论的精度和证据边界 |

这些内容非常适合训练专业认知。

但 Creator 必须根据课程目标明确哪些是课标内、哪些属于进阶拓展，提供必要的先备知识和数学降维，不能把未学习的高中或大学理论直接作为初中考试达标要求。

例如，终极速度可以先通过"速度—阻力—合力—加速度"的定性反馈关系理解，再使用简单离散数值模拟，而不必先学习微分方程。

# 十五、建议的首个物理学科包金标准

参考几何学科包以代表性章节作为金标准的经验，我建议不要用"牛顿第一定律讲解课"作为物理学科包的唯一验证标杆。

应该选择一个能够覆盖深层专家认知、多模型组合、动态预测、实验验证和模型修订的主题。

## 推荐金标准 A：从自由落体到终极速度

| 维度      | 内容                                    |
| ------- | ------------------------------------- |
| 真实现象    | 不同形状的轻质纸片或咖啡滤纸下落速度不同，部分情况下会接近稳定速度。    |
| 专业认知训练  | 建立相互作用模型，预测阻力、合力、加速度和速度如何共同演化。        |
| 实验与模型修订 | 使用安全的轻质物体、视频或测量数据检验运动趋势，并分析模型简化及测量限制。 |
![[Pasted image 20261127143950.png]]
![[Pasted image 20261127144007.png]]
![[Pasted image 20261127144025.png]]完整训练链应覆盖：

| 环节 | 学生任务 |
| ---- | ---- |
| 前测 | 区分速度、加速度和合力 |
| 机制建模 | 构建重力与空气阻力模型 |
| 心中预测 | 预测整个下落过程的动态变化 |
| 多表征 | 画受力图、速度图和加速度趋势 |
| 实验 | 检验预测与真实下落现象 |
| 修订 | 解释偏差和测量不确定性 |
| 定量拓展 | 根据给定简化模型进行计算或数值模拟 |
| 独立迁移 | 改变物体质量、迎风面积或阻力条件 |
| 创造应用 | 设计控制下落速度的装置并验证 |

这一主题与此前规划的力学提高课程高度契合，也具有很强的 PBL 拓展潜力。

但单纯观察物体接近稳定速度，并不能鉴别阻力究竟正比于速度还是速度的平方。若要评价阻力定律，需要额外设计实验与数据分析。

## 推荐金标准 B：浮力全过程与系统边界

重点验证初中压轴题所需的认知能力。

包含物体浸入、完全浸没、悬挂、漂浮、接触容器等不同条件下的模型切换，重点训练：

`对象切换 → 排液体积 → 浮力关系 → 受力平衡 → 容器与液体响应 → 临界点`

适合检验学生能否在不同研究对象之间切换，并保持物理量和系统状态的一致性。

## 推荐金标准 C：从电路拓扑到动态电路心理运行

用于检验物理学科包是否真正具备跨力学复用价值。

包含开关变化、电路连接关系、等效电阻、仪表示数变化、异常故障诊断及能量传递。

其高阶训练是学生不需要先运行电路仿真，就能够在头脑中预测：

**开关改变后哪些连接发生变化？电流如何重新分配？各仪表测量对象是否改变？哪些结论依赖理想电源或理想电表假设？**

如果三个金标准可以共用主要技能和训练规格，同时保留各自领域规则，就能够有力支持建立统一 `physics-modeling.md` 的架构决策。

# 十八、与现有三个学科包的横向比较

![[Pasted image 20261127144134.png]]

这四个学科包有着共同的高阶认知机制，但最终的专业验证方式不同。

| 领域 | 专业对象 | 高阶操作 | 最终验证 |
| ---- | ---- | ---- | ---- |
| 几何 | 几何结构 | 构型变换与辅助构造 | 数学证明 |
| 写作 | 意义与表达 | 意义重构与篇章创造 | 作品质量、表达目的与读者反馈 |
| AI 工程 | 智能系统 | 心理运行与系统重构 | 测试、运行证据、真实价值 |
| 物理 | 自然现象及模型 | 机制推演与模型创造 | 理论一致性、实验及观测证据 |

物理与几何最大的区别是，数学证明可以在公理和题设成立的条件下推出必然结论；物理模型即使数学推导完全正确，也仍然需要检查其假设是否适用于真实系统。

物理最深刻的学科思维，恰恰是在人创造的抽象模型与真实世界之间不断往返。

# 二十、最终建议

我建议将物理学科包的教育哲学归纳为六个递进的专业认知动作。

![[Pasted image 20261127144228.png]]
这六个动作不是固定课堂程序，而是一个可以反复往返、不断深化的物理认识过程。

如果只能从大量物理教育研究中选择五个最重要的研究支点，我会优先选择：

- **Chi**：从表面情境识别深层物理原理。
- **Clement**：通过心理模拟、类比和思想实验创造模型。
- **Hestenes**：以模型发展与模型运用组织物理学习。
- **Etkina**：通过科学探究、实验和证据建构知识。
- **Kuo、Docktor 等**：将物理意义、数学推理和能力评价连接起来。

它们共同构成了从物理专家认知到教学、训练、测评和真实实践的研究底座。

> 真正高质量的中学物理教育，不是培养一个能够熟练解答所有已知题型的学生，而是培养一个面对未知自然现象，能够在头脑中建立物理世界、推演其运行规律、用数学作出预测、用实验检验自己的理解，并最终利用这些规律创造新事物的人。
