## 四、10-26 晚上新增、务必遵守的事实

- **macOS 本地网络权限**：Homebrew 的 Python 以 `Python.app` 运行，系统把它当作独立应用。用户已经给 Python 授权，所以从终端跑批跑可以连上 NUC。**执行方工具里启动的 Python 可能仍然连不上 NUC**（连接会一直等到超时）。凡是需要从 Python 连接 NUC 的验证，请用户在终端里跑，或者直接用 bash 调用 ssh。
- **NUC 安全**（`5c58c61`、`0f7aac3`）：所有远端命令都经过 `bounded_remote` 包装（超时、`nice`、`ionice`，第二、三层核验加 `flock` 单实例锁）；只在连接根本没建立时才重试。**不得绕过这些包装，直接 ssh 跑没有超时的重活。**
- **清理 NUC 进程时**，只能用精确条件匹配（例如命令行以 `python3 -c` 开头且包含 `hashlib`），不能用宽泛的 `pkill -f` 模式：10-26 曾因此误杀了执行清理的 shell 自身，在本机也误断了用户的交互式 SSH 会话。
- 用户的 hermes 网关（`/home/hp/.hermes/...`）是用户自己的服务，不要碰。
- 批跑期间，执行方不得改代码、不得跑测试（手册 §0.4 第 11 条）。
