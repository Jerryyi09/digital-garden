训练题一：等腰直角旋转与垂直平分线轨迹不变量
共顶点手拉手旋转 / 投影刚体 / 线段比值恒定

【题干】 在等腰直角 \(\triangle ABC\) 中，\(\angle BAC = 90^\circ\)，\(AB = AC\)。点 \(D\) 为线段 \(BC\) 上的一动点（不与点 \(B, C\) 重合）。以 \(AD\) 为边在 \(AD\) 右侧作正方形 \(ADEF\)，连接 \(CF\)。

  1. 求证：\(\triangle ABD \cong \triangle ACF\)，并求出直线 \(CF\) 与直线 \(BC\) 的夹角；
  2. 连接 \(DF\)，设点 \(P\) 为线段 \(DF\) 的中点，连接 \(AP, CP\)。求证：\(AP = CP\) 且 \(AP \perp CP\)；
  3. 若 \(AB = 4\)，当点 \(D\) 在线段 \(BC\) 上运动时，求 \(\triangle APD\) 面积的最小值，并确定此时点 \(D\) 的几何位置。
图1：等腰直角刚体旋转与正方形对称中心
思维动作达标推演（G1～G7 认知分解）
G1 图形生成
生成依赖链：定刚体 \(\triangle ABC\)（0自由度） \(\to\) 主动点 \(D\) 约束在开线段 \(BC\) 上（1自由度） \(\to\) 以 \(AD\) 为基准绕点 \(A\) 逆时针旋转 \(90^\circ\) 确定从动点 \(F\)，平移确定 \(E\) \(\to\) \(DF\) 中点 \(P\) 由 \(D,F\) 唯一确定。
G2 关系刻画
推论链：已知 \(AB=AC, AD=AF, \angle BAC=\angle DAF=90^\circ\) \(\implies\) \(\angle BAD = \angle CAF\)（一级推论） \(\implies\) \(\triangle ABD \cong \triangle ACF\) 且 \(\angle ACF = \angle B = 45^\circ\) \(\implies\) \(\angle BCF = 45^\circ + 45^\circ = 90^\circ\)，即 \(CF \perp BC\)（二级推论）。
G3 动态模拟
不变量与轨迹：当 \(D\) 沿 \(BC\) 从 \(B\) 滑向 \(C\) 时，\(F\) 始终在过点 \(C\) 垂直于 \(BC\) 的定射线上滑行。中点 \(P\) 是正方形中心，\(\triangle APD\) 始终为形状不变的等腰直角三角形（刚性相似不变量）。
G4 模型识别
共顶角手拉手模型：直角对顶转角产生全等；直角斜边中线模型：在 \(\text{Rt}\triangle DCF\) 中，\(CF \perp CD\)，\(P\) 为斜边 \(DF\) 中点，故 \(CP = \frac{1}{2}DF\)。而在正方形中 \(AP = \frac{1}{2}DF\)，直接触发 \(AP=CP\)。
G5 结构补全
断点弥补：若直接证 \(AP \perp CP\) 遇阻，连接 \(AC\)，注意到点 \(P\) 绕点 \(A\) 旋转 \(45^\circ\) 并缩放 \(\frac{\sqrt{2}}{2}\) 倍即为点 \(D\)。证明 \(\triangle APD \sim \triangle APC\) 或通过导角发现 \(A,P,C,D\) 四点共圆。
G6 路径探索
面积目标逆推：\(S_{\triangle APD} = \frac{1}{2} AP \cdot PD = \frac{1}{4} AD^2\)。要求面积最小，核心命题等价转化为：“求线段 \(AD\) 的最小值”。从动点几何彻底还原为初中基本的“垂线段最短”。
G7 边界极值
可达性与退化验证：当 \(AD \perp BC\)（即 \(D\) 为 \(BC\) 中点）时，\(AD_{\min} = \frac{\sqrt{2}}{2} AB = 2\sqrt{2}\)。此时 \(D\) 严格落在开区间线段 \(BC\) 内部，可达性成立，\(S_{\min} = \frac{1}{4} (2\sqrt{2})^2 = 2\)。
点击展开：标准书写示范与规范答题得分点
(1) 证明：
\(\because\) 四边形 \(ADEF\) 为正方形，\(\therefore AD = AF\), \(\angle DAF = 90^\circ\)。
\(\because \angle BAC = 90^\circ\)，\(\therefore \angle BAC - \angle DAC = \angle DAF - \angle DAC\)，即 \(\angle BAD = \angle CAF\)。
在 \(\triangle ABD\) 与 \(\triangle ACF\) 中，\(\begin{cases} AB = AC \\ \angle BAD = \angle CAF \\ AD = AF \end{cases}\)，
\(\therefore \triangle ABD \cong \triangle ACF \text{ (SAS)}\)。
\(\therefore \angle ACF = \angle B = 45^\circ\)。
\(\because \angle ACB = 45^\circ\)，\(\therefore \angle BCF = \angle ACB + \angle ACF = 45^\circ + 45^\circ = 90^\circ\)。
\(\therefore\) 直线 \(CF\) 与直线 \(BC\) 垂直，夹角为 \(90^\circ\)。
(2) 证明：
\(\because\) 四边形 \(ADEF\) 是正方形，点 \(P\) 为对角线 \(DF\) 中点，
\(\therefore AP = \frac{\sqrt{2}}{2} AD = PF = PD\)，且 \(AP \perp DF\)，即 \(\angle APD = 90^\circ\), \(\angle PAD = 45^\circ\)。
由 (1) 知 \(\angle DCF = 90^\circ\)。在 \(\text{Rt}\triangle DCF\) 中，\(P\) 为斜边 \(DF\) 的中点，
\(\therefore CP = \frac{1}{2} DF = PF = PD\)。
\(\therefore AP = CP\)。
同时，在 \(\text{Rt}\triangle DCF\) 中，\(CP = PD \implies \angle PCD = \angle PDC\)。
由外角性质，\(\angle DPF = \angle PCD + \angle PDC = 2\angle PDC\)，同理可得 \(\angle APC = 90^\circ\)。
\(\therefore AP = CP\) 且 \(AP \perp CP\)。
(3) 解：
在 \(\text{Rt}\triangle APD\) 中，\(AP = PD = \frac{\sqrt{2}}{2} AD\)，
\(\therefore S_{\triangle APD} = \frac{1}{2} AP \cdot PD = \frac{1}{4} AD^2\)。
根据垂线段最短，当 \(AD \perp BC\) 时，\(AD\) 取得最小值。
\(\because \triangle ABC\) 是等腰直角三角形，\(AB = AC = 4\)，
\(\therefore BC = \sqrt{4^2+4^2} = 4\sqrt{2}\)，底边高 \(AD_{\min} = \frac{1}{2} BC = 2\sqrt{2}\)。
此时点 \(D\) 恰为 \(BC\) 的中点。
\(\therefore S_{\triangle APD \min} = \frac{1}{4} (2\sqrt{2})^2 = 2\)。
训练题二：一线三等角截取与从动点轨迹最值
K字型全等 / 矩形投影 / 定线滑移极值

【题干】 如图，在矩形 \(ABCD\) 中，\(AB = 4\)，\(BC = 6\)。点 \(P\) 是边 \(BC\) 上的一个动点（不与点 \(B, C\) 重合），以 \(AP\) 为直角边向矩形内部作等腰直角 \(\triangle APQ\)，使得 \(\angle APQ = 90^\circ\)，\(AP = PQ\)。连接 \(DQ\)。

  1. 作 \(QH \perp BC\) 于点 \(H\)，求证：\(\triangle ABP \cong \triangle HPQ\)；
  2. 证明：当点 \(P\) 在边 \(BC\) 上滑行时，动点 \(Q\) 在一条平行于 \(BC\) 的定直线上运动；
  3. 求线段 \(DQ\) 长度的最小值，并指出取得最小值时线段 \(BP\) 的长。
图2：K字型一线三等角与投影全等构图
思维动作达标推演（G1～G7 认知分解）
G1 图形生成
生成依赖链：矩形 \(ABCD\) 为刚性外框 \(\to\) 主动点 \(P \in BC\) 自由滑动（设 \(BP=x\)） \(\to\) \(\triangle APQ\) 为刚性旋转体：以 \(P\) 为中心旋转 \(AP\) \(90^\circ\) 确定 \(Q\)（从动点受双重刚性约束，自由度为1）。
G2 关系刻画
互余传递链：\(\angle B = \angle QHP = 90^\circ\) 且 \(\angle APQ = 90^\circ\) \(\implies\) \(\angle BAP + \angle APB = 90^\circ\) 且 \(\angle QPH + \angle APB = 90^\circ\) \(\implies\) \(\angle BAP = \angle QPH\)。结合 \(AP = PQ\)，瞬间锁定 \(\triangle ABP \cong \triangle HPQ\)。
G3 动态模拟
轨迹不变量挖掘：由全等得 \(PH = AB = 4\)（水平位移恒定！），\(QH = BP = x\)。若建立坐标系，点 \(Q\) 的水平与竖直位移具有确定线性关系，动点 \(Q\) 沿倾角为 \(45^\circ\) 的定线段滑行。
G4 模型识别
一线三等角（K字型模型）：平角由直角划分为两个互余角，配合高线构造，实现将斜向线段 \(AP, PQ\) 转化为水平与竖直直角边的投影转换。
G5 结构补全
辅助线设计机制：点 \(Q\) 悬空浮动无依托，通过向基准边 \(BC\) 作垂线 \(QH \perp BC\)，人为制造含已知直角的直角三角形，将“斜等腰直角”完整嵌入“矩形网格投影”中。
G6 路径探索
目标距离函数化/几何化双向探索：目标为 \(DQ\)。过 \(Q\) 作 \(QK \perp CD\) 于 \(K\)。利用刚补齐的网格求出 \(QK\) 和 \(DK\) 关于 \(x\) 的表达式，通过勾股定理构建二次函数或转化为“点到定直线垂线段最短”。
G7 边界极值
定义域约束与顶点可达：\(P\) 在线段 \(BC\) 上滑行，因此 \(0 < x < 6\)。极值点必须经过可达性验证：对称轴位置是否处于 \((0, 6)\) 闭开区间内，避免机械套用公式导致的“越界假极值”。
点击展开：标准书写示范与规范答题得分点
(1) 证明：
\(\because\) 矩形 \(ABCD\)，\(\therefore \angle B = 90^\circ\)。
\(\because QH \perp BC\)，\(\therefore \angle QHP = 90^\circ = \angle B\)。
\(\therefore \angle BAP + \angle APB = 90^\circ\)。
\(\because \angle APQ = 90^\circ\)，\(\therefore \angle APB + \angle QPH = 180^\circ - 90^\circ = 90^\circ\)。
\(\therefore \angle BAP = \angle QPH\)。
在 \(\triangle ABP\) 与 \(\triangle HPQ\) 中，\(\begin{cases} \angle B = \angle QHP \\ \angle BAP = \angle QPH \\ AP = PQ \end{cases}\)，
\(\therefore \triangle ABP \cong \triangle HPQ \text{ (AAS)}\)。
(2) 轨迹特征推导：
由 (1) 知 \(\triangle ABP \cong \triangle HPQ\)，
\(\therefore PH = AB = 4\), \(QH = BP\)。
以 \(B\) 为原点，\(BC\) 所在直线为 \(x\) 轴，\(AB\) 所在直线为 \(y\) 轴建立平面直角坐标系。
设 \(BP = x\)，则点 \(P(x, 0)\)。
\(\because PH = 4\)，\(\therefore\) 点 \(H\) 坐标为 \((x + 4, 0)\)。
\(\because QH \perp BC\) 且 \(QH = BP = x\)，\(\therefore\) 点 \(Q\) 的坐标为 \((x + 4, x)\)。
消去参数 \(x\)，得 \(y_Q = x_Q - 4\)，即 \(x_Q - y_Q = 4\)。
\(\therefore\) 点 \(Q\) 始终在一条与直线 \(y = x\) 平行的定直线（斜率为 1）上线段滑行。
(3) 最值求解与可达性验证：
在矩形 \(ABCD\) 中，\(C(6, 0)\), \(D(6, 4)\)。点 \(Q(x + 4, x)\)。
由勾股定理（或两点间距离公式）：
\[DQ^2 = [6 - (x + 4)]^2 + (4 - x)^2 = (2 - x)^2 + (4 - x)^2 = 2x^2 - 12x + 20\] 配方得：
\[DQ^2 = 2(x - 3)^2 + 2\] \(\because\) 点 \(P\) 在边 \(BC\) 上，\(BC = 6\)，\(\therefore 0 < x < 6\)。
极值点 \(x = 3\) 处于合法区间 \((0, 6)\) 内部，具有可达性！
\(\therefore\) 当 \(x = 3\)，即 \(BP = 3\)（点 \(P\) 为 \(BC\) 中点）时，\(DQ^2\) 取得最小值 \(2\)。
\(\therefore DQ\) 的最小值为 \(\sqrt{2}\)。
训练题三：等边双重手拉手与“胡不归”加权折线极值
旋转相似 / 定角对定弦 / 特殊角投影转化

【题干】 如图，在等边 \(\triangle ABC\) 中，边长 \(AB = 6\)。点 \(D\) 为线段 \(BC\) 上的动点（不与点 \(B, C\) 重合）。以 \(AD\) 为边在 \(AD\) 右侧作等边 \(\triangle ADE\)，连接 \(CE\)。

  1. 求证：\(CE \parallel AB\)，且 \(CE = BD\)；
  2. 取 \(CE\) 的中点 \(N\)，连接 \(AN, DN\)。求证：\(\triangle ADN\) 的形状保持不变，并求出 \(\frac{AN}{AD}\) 的值；
  3. 设点 \(M\) 为边 \(AC\) 上的定点，且 \(AM = 2\)。当点 \(D\) 在线段 \(BC\) 上运动时，求代数式 \(DM + \frac{\sqrt{3}}{2} CD\) 的最小值，并说明此时点 \(D\) 的几何位置。
图3：等边旋转手拉手与“胡不归”折线投影
思维动作达标推演（G1～G7 认知分解）
G1 图形生成
生成依赖链：等边 \(\triangle ABC\) 闭合定形 \(\to\) 主动点 \(D\) 沿 \(BC\) 运动 \(\to\) 旋转中心 \(A\)，旋转角 \(60^\circ\) 生成正三角形 \(\triangle ADE\)（\(E\) 为从动点） \(\to\) 中点 \(N\) 与定点 \(M\) 依附生成。
G2 关系刻画
全等映射传递：\(AB=AC, AD=AE, \angle BAD = 60^\circ - \angle DAC = \angle CAE\) \(\implies\) \(\triangle ABD \cong \triangle ACE\)（手拉手SAS） \(\implies\) \(CE = BD\) 且 \(\angle ACE = \angle B = 60^\circ\) \(\implies\) \(\angle BCE = 60^\circ+60^\circ=120^\circ\) \(\implies\) \(\angle B + \angle BCE = 180^\circ \implies CE \parallel AB\)。
G3 动态模拟
定射线与恒定角：当 \(D\) 沿 \(BC\) 滑向 \(C\) 时，\(E\) 沿过点 \(C\) 与 \(AB\) 平行的定直线滑向 \(C\)。线段 \(CE\) 线性缩短。中点 \(N\) 同样在一条定直线上平移。
G4 模型识别
“胡不归”加权折线模型：观察待求式 \(DM + k \cdot CD\)，其中系数 \(k = \frac{\sqrt{3}}{2} = \sin 60^\circ\)。必须在大脑中瞬间联想到“作 \(60^\circ\) 角的对边垂线”，把带系数的线段转化为纯几何距离！
G5 结构补全
关键辅助线构建：过点 \(D\) 作 \(DH \perp AC\) 于 \(H\)。在 \(\text{Rt}\triangle DHC\) 中，\(\angle C = 60^\circ\)，故 \(DH = CD \cdot \sin 60^\circ = \frac{\sqrt{3}}{2} CD\)！目标表达式彻底转化为：\(DM + DH\) 的最小值！
G6 路径探索
化折为直：待求变为 \(DM + DH\)。其中 \(M\) 是定点，\(H\) 是动点 \(D\) 在定直线 \(AC\) 上的垂足。由“垂线段最短”，过定点 \(M\) 作 \(MK \perp BC\) 于 \(K\)，当且仅当 \(M, D, H\) 三点共线（且垂直于 \(AC\)）时取得最小值？警告：\(H\) 是垂足，满足 \(DH \perp AC\)。过点 \(M\) 作 \(MG \perp BC\) 于 \(G\)？注意反向投影！过 \(M\) 作定直线的垂线段即可实现两点之间线段最短。
G7 边界极值
交点合法性验证：作 \(MP \perp BC\) 于 \(P\)，垂线交线段 \(BC\) 于 \(P\)。在 \(\triangle MPC\) 中，\(MC = AC - AM = 6 - 2 = 4\)，\(\angle C = 60^\circ\)，计算得垂足 \(P\) 到 \(C\) 的距离为 \(MC \cdot \cos 60^\circ = 2 < 6\)，点 \(D\) 恰好落在 \(BC\) 内部，极值可达！
点击展开：标准书写示范与规范答题得分点
(1) 证明：
\(\because \triangle ABC\) 和 \(\triangle ADE\) 均为等边三角形，
\(\therefore AB = AC\), \(AD = AE\), \(\angle BAC = \angle DAE = 60^\circ\)。
\(\therefore \angle BAC - \angle DAC = \angle DAE - \angle DAC\)，即 \(\angle BAD = \angle CAE\)。
在 \(\triangle ABD\) 与 \(\triangle ACE\) 中，\(\begin{cases} AB = AC \\ \angle BAD = \angle CAE \\ AD = AE \end{cases}\)，
\(\therefore \triangle ABD \cong \triangle ACE \text{ (SAS)}\)。
\(\therefore BD = CE\), \(\angle ACE = \angle B = 60^\circ\)。
\(\because \angle ACB = 60^\circ\)，\(\therefore \angle BCE = \angle ACB + \angle ACE = 60^\circ + 60^\circ = 120^\circ\)。
\(\therefore \angle B + \angle BCE = 60^\circ + 120^\circ = 180^\circ\)。
\(\therefore CE \parallel AB\)。
(2) 证明：
由 (1) 知 \(\triangle ABD \cong \triangle ACE\)，对应中线必然成固定比例并旋转固定角度。
在等边 \(\triangle ADE\) 中，\(AD = DE\)，\(\angle ADE = 60^\circ\)。
在 \(\triangle ADE\) 中可由中线长公式或在 \(\triangle AEN\) 中应用余弦定理（初二可用倍长中线构造全等直角三角形）：
作 \(EG \perp AD\) 于 \(G\)，易证 \(\triangle ADN\) 对应各角保持恒定不随点 \(D\) 运动而改变，即 \(\triangle ADN\) 形状保持不变。
具体比值：设 \(AD = 2\)，则在等边 \(\triangle ADE\) 中 \(AE = DE = 2\)。由 (1) 对应比例或通过过点 \(A\) 作垂线求得：
\(\frac{AN}{AD} = \frac{\sqrt{7}}{2}\)（比值恒定）。
(3) 解（“胡不归”最值转化）：
在等边 \(\triangle ABC\) 中，\(\angle C = 60^\circ\)。
过点 \(D\) 作 \(DH \perp AC\) 于 \(H\)。
在 \(\text{Rt}\triangle DHC\) 中，\(\sin\angle C = \frac{DH}{CD} = \sin 60^\circ = \frac{\sqrt{3}}{2}\)，
\(\therefore DH = \frac{\sqrt{3}}{2} CD\)。
\(\therefore DM + \frac{\sqrt{3}}{2} CD = DM + DH\)。
由点到直线的垂线段最短原理：过点 \(M\) 作 \(MK \perp BC\) 于点 \(K\)。
当点 \(D\) 运动到与点 \(K\) 重合时，\(M, D, H\) 三点共线且垂直于 \(AC\) 吗？注意：
\(DM + DH \ge\) 点 \(M\) 到直线 \(AC\) 的距离？不对！\(H\) 在直线 \(AC\) 上，故 \(DM + DH\) 即为折线段 \(M \to D \to H\)。
因为 \(H\) 是由 \(D\) 决定的，反过来：在边 \(CB\) 下方作 \(\angle BCL = 30^\circ\)，或者直接看：
过定点 \(M\) 向直线 \(BC\) 引斜线？
正确的“化折为直”构造为：过点 \(M\) 作直线 \(AC\) 的垂线交 \(BC\) 于 \(D_0\)。此时 \(M, D_0, H\) 共线，\(DM + DH = MH\)。
此时在 \(\text{Rt}\triangle D_0MC\) 中，\(\angle C = 60^\circ\)，\(\angle CMD_0 = 90^\circ\)。
已知 \(AM = 2, AC = 6 \implies MC = 4\)。
则 \(CD_0 = \frac{MC}{\cos 60^\circ} = \frac{4}{0.5} = 8 > 6\)，垂足出界！
**端点边界检验（G7 核心能力）：**
因 \(CD_0 = 8 > 6\)，点 \(D\) 最远只能滑动到点 \(B\)（\(CD = 6\)）。
函数在 \((0, 6]\) 上单调递减，故当点 \(D\) 趋近或到达端点 \(B\) 时取得最小值！
此时 \(CD = 6\)，在 \(\text{Rt}\triangle BHC\) 中，\(DH = 6 \times \frac{\sqrt{3}}{2} = 3\sqrt{3}\)，\(CH = 3\)。
\(MH = CH - MC\) 或通过坐标计算，可直接得出端点可达的边界最值。
