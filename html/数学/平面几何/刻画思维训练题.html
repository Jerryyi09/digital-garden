训练题一：等腰直角手拉手旋转与中垂线轨迹极值
手拉手全等 / 直角斜边中线 / 三线合一中垂线轨迹

【题干】 在等腰直角 \(\triangle ABC\) 中，\(\angle BAC = 90^\circ\)，\(AB = AC = 4\)。点 \(D\) 为线段 \(BC\) 上的一动点（不与点 \(B, C\) 重合）。以 \(AD\) 为边在 \(AD\) 右侧作正方形 \(ADEF\)（顶点 \(A, D, E, F\) 按逆时针排列），连接 \(CF\)。

  1. 求证：\(\triangle ABD \cong \triangle ACF\)，并求 \(\angle BCF\) 的度数；
  2. 连接 \(DF\)，设点 \(P\) 为对角线 \(DF\) 的中点，点 \(M\) 为边 \(AC\) 的中点，连接 \(AP, CP, PM\)。求证：\(AP = CP\)，且直线 \(PM \perp AC\)；
  3. 当点 \(D\) 在线段 \(BC\) 上运动时，求线段 \(CP\) 长度的最小值及此时 \(\triangle APD\) 的面积，并说明此时点 \(D\) 的几何位置。
图1：斜边中线导出 \(AP=CP\)，锁定点 \(P\) 沿 \(AC\) 垂直平分线运动
思维动作达标推演（G1～G7 认知分解）
G1 图形生成
生成依赖链：定刚体 \(\triangle ABC\)（0自由度） \(\to\) 主动点 \(D\) 在开线段 \(BC\) 上滑动（1自由度） \(\to\) 线段 \(AD\) 绕点 \(A\) 逆时针旋转 \(90^\circ\) 生成 \(AF\)，确定正方形 \(ADEF\) \(\to\) 对角线中点 \(P\) 由 \(D,F\) 唯一确定。
G2 关系刻画
推论链：\(\angle BAC = \angle DAF = 90^\circ \implies \angle BAD = \angle CAF\)（一级推论） \(\implies \triangle ABD \cong \triangle ACF \text{ (SAS)} \implies \angle ACF = \angle B = 45^\circ \implies \angle BCF = \angle ACB + \angle ACF = 90^\circ\)（二级推论：\(CF \perp BC\)）。
G3 动态模拟
轨迹与不变量：当 \(D\) 沿 \(BC\) 运动时，从动点 \(F\) 沿垂直于 \(BC\) 的定射线 \(CF\) 运动；由于 \(AP = CP\) 恒成立，从动点 \(P\) 始终被约束在线段 \(AC\) 的垂直平分线 \(PM\) 上滑动。
G4 模型识别
共顶点旋转全等（手拉手） + 直角三角形斜边中线模型（在 \(\text{Rt}\triangle DCF\) 中斜边中线 \(CP = \frac{1}{2}DF\)） + 等腰三角形三线合一模型（由 \(AP=CP\) 且 \(M\) 为 \(AC\) 中点导出 \(PM \perp AC\)）。
G5 结构补全
对角线中点桥梁：面对分散的 \(AP\) 与 \(CP\)，利用点 \(P\) 既是正方形中心（\(AP = \frac{1}{2}DF\)）又是 \(\text{Rt}\triangle DCF\) 斜边中点（\(CP = \frac{1}{2}DF\)）的双重身份，以 \(\frac{1}{2}DF\) 为桥梁完成等量传递。
G6 路径探索
双路径交叉验证：求 \(CP\) 最小值有两条等价路线：① 从动点轨迹视角：\(P\) 在 \(AC\) 的中垂线上运动，当 \(P\) 与垂足 \(M\) 重合时 \(CP\) 最小，即 \(CP_{\min} = CM = 2\)；② 主动点转化视角：\(CP = AP = \frac{\sqrt{2}}{2}AD\)，当 \(AD \perp BC\) 时 \(AD\) 最小。
G7 边界极值
退化与可达性：当 \(D\) 为 \(BC\) 中点（\(AD \perp BC\)）时，四边形 \(ADCF\) 恰好为正方形，此时对角线 \(DF\) 与 \(AC\) 的中点重合（即点 \(P\) 与点 \(M\) 重合），\(D\) 严格位于线段 \(BC\) 内部，极值存在且可达。
点击展开：标准规范证明与双视角极值推导
(1) 证明：
\(\because\) 四边形 \(ADEF\) 为正方形，\(\therefore AD = AF\)，\(\angle DAF = 90^\circ\)。
\(\because \angle BAC = 90^\circ\)，\(\therefore \angle BAC - \angle DAC = \angle DAF - \angle DAC\)，即 \(\angle BAD = \angle CAF\)。
在 \(\triangle ABD\) 与 \(\triangle ACF\) 中，\(\begin{cases} AB = AC \\ \angle BAD = \angle CAF \\ AD = AF \end{cases}\)，
\(\therefore \triangle ABD \cong \triangle ACF \text{ (SAS)}\)。
\(\therefore \angle ACF = \angle B = 45^\circ\)。
\(\because \angle ACB = 45^\circ\)，\(\therefore \angle BCF = \angle ACB + \angle ACF = 45^\circ + 45^\circ = 90^\circ\)。
(2) 证明：
\(\because\) 四边形 \(ADEF\) 是正方形，点 \(P\) 为对角线 \(DF\) 的中点，
\(\therefore\) 正方形对角线相等且互相平分，得 \(AP = \frac{1}{2}DF\)。
由 (1) 知 \(\angle DCF = \angle BCF = 90^\circ\)。
在 \(\text{Rt}\triangle DCF\) 中，点 \(P\) 为斜边 \(DF\) 的中点，由直角三角形斜边中线定理得：
\(CP = \frac{1}{2}DF\)。
\(\therefore AP = CP\)（即点 \(P\) 到线段 \(AC\) 两端点的距离相等，点 \(P\) 恒在线段 \(AC\) 的垂直平分线上）。
又 \(\because\) 点 \(M\) 为线段 \(AC\) 的中点，由等腰三角形“三线合一”（或垂直平分线判定定理）可知，当 \(P\) 与 \(M\) 不重合时，\(PM \perp AC\)。
(3) 解：
视角一（利用主动点 \(D\) 转化）：
在正方形 \(ADEF\) 中，\(\triangle APD\) 为等腰直角三角形，\(AP = PD = \frac{\sqrt{2}}{2}AD\)。
由 (2) 知 \(CP = AP = \frac{\sqrt{2}}{2}AD\)，且 \(S_{\triangle APD} = \frac{1}{2}AP \cdot PD = \frac{1}{4}AD^2\)。
由垂线段最短可知，当 \(AD \perp BC\)（即点 \(D\) 为斜边 \(BC\) 的中点）时，\(AD\) 取得最小值。
\(\because AB = AC = 4\)，\(\angle BAC = 90^\circ\)，\(\therefore BC = 4\sqrt{2}\)，\(AD_{\min} = \frac{1}{2}BC = 2\sqrt{2}\)。
\(\therefore CP_{\min} = \frac{\sqrt{2}}{2} \times 2\sqrt{2} = 2\)，此时 \(\triangle APD\) 面积的最小值为 \(S_{\min} = \frac{1}{4} \times (2\sqrt{2})^2 = 2\)。
视角二（利用从动点 \(P\) 的轨迹验证）：
由 (2) 知点 \(P\) 在线段 \(AC\) 的垂直平分线上运动，当点 \(P\) 运动至垂足 \(M\)（即 \(AC\) 中点）时，\(CP\) 最小，最小值为 \(CM = \frac{1}{2}AC = 2\)，两种视角结论完全一致。
训练题二：一线三直角（K字型）与截长平移定角轨迹
K字型全等 / 线段平移消元 / 定射线垂线段极值

【题干】 如图，在矩形 \(ABCD\) 中，\(AB = 4\)，\(BC = 6\)。点 \(E\) 为边 \(AB\) 上的定点，且 \(BE = 2\)。点 \(P\) 是边 \(BC\) 上的一个动点（不与点 \(B, C\) 重合），以 \(EP\) 为直角边在 \(EP\) 右侧作等腰直角 \(\triangle EPQ\)，使得 \(\angle EPQ = 90^\circ\)，\(EP = PQ\)。过点 \(Q\) 作 \(QH \perp BC\)，交直线 \(BC\) 于点 \(H\)。

  1. 求证：\(\triangle EBP \cong \triangle PHQ\)，并求出线段 \(PH\) 的长度；
  2. 在边 \(BC\) 上取定点 \(M\)，使得 \(BM = 2\)，连接 \(QM\)。求证：当点 \(P\) 在边 \(BC\) 上运动时，\(\angle QMC\) 的度数保持不变，并求出该度数；
  3. 连接 \(CQ\)，当点 \(P\) 在边 \(BC\) 上运动时，求线段 \(CQ\) 长度的最小值，并求出此时线段 \(BP\) 的长。
图2：由 \(PH=BM=2\) 导出 \(MH=BP=QH\)，锁定 \(\angle QMC=45^\circ\)
思维动作达标推演（G1～G7 认知分解）
G1 图形生成
生成依赖链：矩形 \(ABCD\) 与定点 \(E(BE=2)\) 固定 \(\to\) 主动点 \(P\) 沿边 \(BC\) 移动 \(\to\) 线段 \(EP\) 绕点 \(P\) 顺时针旋转 \(90^\circ\) 生成从动点 \(Q\) \(\to\) 向 \(BC\) 投影得垂足 \(H\)。
G2 关系刻画
同角余角传递链：\(\angle B = \angle QHP = 90^\circ\)，\(\angle EPQ = 90^\circ \implies \angle BPE + \angle QPH = 90^\circ\)，又 \(\angle BPE + \angle BEP = 90^\circ \implies \angle BEP = \angle QPH\)。结合 \(EP = PQ\)，得 \(\triangle EBP \cong \triangle PHQ \implies PH = BE = 2, QH = BP\)。
G3 动态模拟
平移守恒与定角轨迹：因为 \(PH = 2\) 恒定，当 \(P\) 移动时，垂足 \(H\) 始终在 \(P\) 右侧保持定距 \(2\) 同步平移。引入定点 \(M(BM=2)\) 后，必有 \(MH = BH - BM = (BP + 2) - 2 = BP = QH\)，从而 \(\angle QMC = 45^\circ\) 保持不变！
G4 模型识别
一线三直角（K字型全等模型）：平角上嵌直角，向基准线作垂线，实现“斜线段等长”向“水平与竖直直角边相等”的坐标化分解。
G5 结构补全
定点补偿消元：已知 \(QH = BP\)，但 \(H\) 随 \(P\) 移动导致 \(\triangle QHP\) 位置游移。通过在 \(BC\) 上截取定点 \(M\) 使 \(BM = PH = 2\)，将动线段 \(BP\) 平移转化为以定点 \(M\) 为端点的线段 \(MH\)，一举构造出定角等腰 \(\text{Rt}\triangle QHM\)。
G6 路径探索
几何轨迹法 vs 代数配方法：① 几何路线：点 \(Q\) 在定射线 \(MQ\)（\(\angle QMC = 45^\circ\)）上运动，过定点 \(C\) 作 \(CQ \perp MQ\) 时 \(CQ\) 最短；② 代数路线：在 \(\text{Rt}\triangle QHC\) 中用 \(BP=x\) 表示 \(QH=x\) 与 \(HC=|4-x|\)，由勾股定理配方求极值。
G7 边界极值
可达性核验：当 \(CQ \perp MQ\) 时，\(\triangle MQC\) 为等腰直角三角形，斜边 \(MC = 6 - 2 = 4\)，垂足 \(H\) 为 \(MC\) 中点，故 \(BP = MH = 2\)。因 \(0 < 2 < 6\)，点 \(P\) 严格在线段 \(BC\) 内部，极值 \(2\sqrt{2}\) 真实可达。
点击展开：标准规范证明与双路径极值求解
(1) 证明：
\(\because\) 四边形 \(ABCD\) 为矩形，\(\therefore \angle B = 90^\circ\)。
\(\because QH \perp BC\)，\(\therefore \angle QHP = 90^\circ = \angle B\)。
\(\because \angle EPQ = 90^\circ\)，\(\therefore \angle BPE + \angle QPH = 180^\circ - 90^\circ = 90^\circ\)。
又 \(\because\) 在 \(\text{Rt}\triangle EBP\) 中，\(\angle BPE + \angle BEP = 90^\circ\)，
\(\therefore \angle BEP = \angle QPH\)。
在 \(\triangle EBP\) 与 \(\triangle PHQ\) 中，\(\begin{cases} \angle B = \angle QHP \\ \angle BEP = \angle QPH \\ EP = PQ \end{cases}\)，
\(\therefore \triangle EBP \cong \triangle PHQ \text{ (AAS)}\)。
\(\therefore PH = BE = 2\)，\(QH = BP\)。
(2) 证明：
由 (1) 知 \(PH = 2\)，\(QH = BP\)。
\(\because\) 点 \(P\) 在边 \(BC\) 上且 \(BM = 2\)，点 \(H\) 在点 \(P\) 右侧，
\(\therefore BH = BP + PH = BP + 2\)。
\(\therefore\) 点 \(H\) 始终位于点 \(M\) 右侧，且 \(MH = BH - BM = (BP + 2) - 2 = BP\)。
\(\therefore MH = QH\)。
又 \(\because QH \perp BC\)，即 \(\angle QHM = 90^\circ\)，
\(\therefore \triangle QHM\) 始终为等腰直角三角形。
\(\therefore \angle QMC = \angle QMH = 45^\circ\)（度数保持不变）。
(3) 解：
方法一（几何轨迹垂线段最短）：
由 (2) 知，当点 \(P\) 在 \(BC\) 上运动时，点 \(Q\) 在过定点 \(M\) 且满足 \(\angle QMC = 45^\circ\) 的射线上运动。
\(\because BC = 6, BM = 2\)，\(\therefore MC = BC - BM = 4\)。
由点到直线的垂线段最短可知，当 \(CQ \perp MQ\) 时，线段 \(CQ\) 取得最小值。
此时 \(\triangle MQC\) 为等腰直角三角形（\(\angle MQC = 90^\circ, \angle QMC = 45^\circ\)），
\(\therefore CQ_{\min} = \frac{\sqrt{2}}{2}MC = 2\sqrt{2}\)。
此时由等腰直角三角形“三线合一”，\(QH \perp MC\) 知点 \(H\) 为 \(MC\) 的中点，故 \(MH = \frac{1}{2}MC = 2\)。
\(\therefore BP = MH = 2\)（满足 \(0 < BP < 6\)，点 \(P\) 恰好与点 \(M\) 重合）。
方法二（代数勾股定理配方法）：
设 \(BP = x\)（\(0 < x < 6\)），则 \(QH = MH = x\)，\(HC = |MC - MH| = |4 - x|\)。
在 \(\text{Rt}\triangle QHC\) 中，由勾股定理得：
\(CQ^2 = QH^2 + HC^2 = x^2 + (4 - x)^2 = 2x^2 - 8x + 16 = 2(x - 2)^2 + 8\)。
当 \(x = 2 \in (0, 6)\) 时，\(CQ^2\) 取得最小值 \(8\)，故 \(CQ_{\min} = 2\sqrt{2}\)，此时 \(BP = 2\)。
训练题三：等边双重手拉手全等与双视角轨迹极值
共顶点60°旋转 / 对应中点二次全等 / 定角射线极值

【题干】 如图，在等边 \(\triangle ABC\) 中，边长 \(AB = 6\)。点 \(D\) 为线段 \(BC\) 上的动点（不与点 \(B, C\) 重合）。以 \(AD\) 为边在 \(AD\) 右侧作等边 \(\triangle ADE\)，连接 \(CE\)。

  1. 求证：\(\triangle ABD \cong \triangle ACE\)，并证明 \(CE \parallel AB\)；
  2. 设点 \(M\) 为线段 \(BD\) 的中点，点 \(N\) 为线段 \(CE\) 的中点，连接 \(AM, AN, MN\)。求证：\(\triangle AMN\) 为等边三角形；
  3. 当点 \(D\) 在线段 \(BC\) 上运动时，求线段 \(AE\) 长度的最小值及此时线段 \(CE\) 的长（请分别从“主动点 \(D\)”与“从动点 \(E\) 轨迹”两个视角加以说明）。
图3：一级手拉手 \(\triangle ABD \cong \triangle ACE\) 衍生二级中点手拉手 \(\triangle ABM \cong \triangle ACN\)
思维动作达标推演（G1～G7 认知分解）
G1 图形生成
生成依赖链：等边 \(\triangle ABC\) 固定 \(\to\) 主动点 \(D\) 沿线段 \(BC\) 移动 \(\to\) 线段 \(AD\) 绕点 \(A\) 逆时针旋转 \(60^\circ\) 生成从动点 \(E\) \(\to\) 分别取 \(BD, CE\) 中点生成从动点 \(M, N\)。
G2 关系刻画
二级推论传递：① 一级推论：\(\triangle ABD \cong \triangle ACE \implies BD = CE\) 且 \(\angle ACE = \angle B = 60^\circ \implies \angle BCE = 120^\circ \implies CE \parallel AB\)；② 二级推论：因 \(M, N\) 为对应边中点，故 \(BM = \frac{1}{2}BD = \frac{1}{2}CE = CN\)，触发二次全等 \(\triangle ABM \cong \triangle ACN \text{ (SAS)}\)。
G3 动态模拟
定射线轨迹与刚体缩放：当 \(D\) 由 \(B\) 向 \(C\) 滑行时，从动点 \(E\) 沿与 \(AB\) 平行的定射线 \(CE\) 远离点 \(C\)（满足 \(0 < CE < 6\)）；与此同时，\(\triangle AMN\) 绕点 \(A\) 旋转并缩放，但始终保持等边三角形的形状不变。
G4 模型识别
共顶点双等边手拉手模型：识别出以 \(A\) 为共顶点的两套全等系统（外层 \(\triangle ABD \cong \triangle ACE\) 与内层中点 \(\triangle ABM \cong \triangle ACN\)），利用旋转角等于顶角 \(60^\circ\) 判定等边三角形。
G5 结构补全
对应点同构映射：要证 \(\triangle AMN\) 为等边三角形，切忌孤立计算三边，而是将 \(M, N\) 视为全等母体 \(\triangle ABD\) 与 \(\triangle ACE\) 内部对应的结构点，直接复用 \(AB=AC, \angle B=\angle ACN=60^\circ, BM=CN\) 一步锁定全等。
G6 路径探索
主从双视角汇合：求 \(AE\) 最小值：① 主动点视角：利用等边性质将从动线段 \(AE\) 转化为主动线段 \(AD\)（\(AE = AD\)），转化为定点 \(A\) 到定线 \(BC\) 的距离；② 从动点视角：直接利用 \(E\) 在定射线 \(CE\)（\(\angle ACE = 60^\circ\)）上的轨迹，作 \(AE \perp CE\) 求垂线段长。
G7 边界极值
合法位置核验：当 \(AE \perp CE\) 时，在 \(\text{Rt}\triangle AEC\) 中 \(\angle ACE = 60^\circ, AC = 6\)，故 \(CE = \frac{1}{2}AC = 3\)。因 \(BD = CE = 3 \in (0, 6)\)，此时 \(D\) 恰为 \(BC\) 中点（严格位于开线段 \(BC\) 内），最优值 \(3\sqrt{3}\) 真实可达。
点击展开：标准规范证明与主从双视角极值推导
(1) 证明：
\(\because \triangle ABC\) 与 \(\triangle ADE\) 均为等边三角形，
\(\therefore AB = AC\)，\(AD = AE\)，\(\angle BAC = \angle DAE = 60^\circ\)。
\(\therefore \angle BAC - \angle DAC = \angle DAE - \angle DAC\)，即 \(\angle BAD = \angle CAE\)。
在 \(\triangle ABD\) 与 \(\triangle ACE\) 中，\(\begin{cases} AB = AC \\ \angle BAD = \angle CAE \\ AD = AE \end{cases}\)，
\(\therefore \triangle ABD \cong \triangle ACE \text{ (SAS)}\)。
\(\therefore \angle ACE = \angle B = 60^\circ\)。
又 \(\because \angle ACB = 60^\circ\)，\(\therefore \angle BCE = \angle ACB + \angle ACE = 60^\circ + 60^\circ = 120^\circ\)。
\(\therefore \angle B + \angle BCE = 60^\circ + 120^\circ = 180^\circ\)（同旁内角互补），
\(\therefore CE \parallel AB\)。
(2) 证明：
由 (1) 知 \(\triangle ABD \cong \triangle ACE\)，\(\therefore BD = CE\)，\(\angle ACN = \angle ACE = \angle B = 60^\circ\)。
\(\because\) 点 \(M\) 为 \(BD\) 的中点，点 \(N\) 为 \(CE\) 的中点，
\(\therefore BM = \frac{1}{2}BD\)，\(CN = \frac{1}{2}CE\)，故 \(BM = CN\)。
在 \(\triangle ABM\) 与 \(\triangle ACN\) 中，\(\begin{cases} AB = AC \\ \angle B = \angle ACN \\ BM = CN \end{cases}\)，
\(\therefore \triangle ABM \cong \triangle ACN \text{ (SAS)}\)。
\(\therefore AM = AN\)，且 \(\angle BAM = \angle CAN\)。
\(\therefore \angle MAN = \angle MAC + \angle CAN = \angle MAC + \angle BAM = \angle BAC = 60^\circ\)。
\(\because AM = AN\) 且 \(\angle MAN = 60^\circ\)，
\(\therefore \triangle AMN\) 为等边三角形。
(3) 解：
视角一（转化为含主动点 \(D\) 的线段）：
\(\because \triangle ADE\) 为等边三角形，\(\therefore AE = AD\)。
点 \(D\) 在线段 \(BC\) 上运动，由垂线段最短可知，当 \(AD \perp BC\) 时，\(AD\)（即 \(AE\)）取得最小值。
在等边 \(\triangle ABC\) 中，\(AB = BC = 6\)，当 \(AD \perp BC\) 时，点 \(D\) 为 \(BC\) 的中点，故 \(BD = 3\)，
此时 \(AE_{\min} = AD_{\min} = \frac{\sqrt{3}}{2}AB = 3\sqrt{3}\)，且 \(CE = BD = 3\)。
视角二（直接基于从动点 \(E\) 的运动轨迹）：
由 (1) 知 \(\angle ACE = 60^\circ\)，且 \(CE = BD \in (0, 6)\)，即从动点 \(E\) 在射线 \(CE\) 上运动。
定点 \(A\) 到定射线 \(CE\) 的距离，当 \(AE \perp CE\) 时取得最小值。
在 \(\text{Rt}\triangle AEC\) 中，\(\angle AEC = 90^\circ\)，\(\angle ACE = 60^\circ\)，\(AC = 6\)，
\(\therefore CE = AC \cdot \cos 60^\circ = 3 \in (0, 6)\)（位置合法且可达），\(AE_{\min} = AC \cdot \sin 60^\circ = 3\sqrt{3}\)。
